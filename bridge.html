WHAT BRIDGE DOES
// HOW IT WORKS
The bridge connects your Termux to the Vault AI terminal. Once connected, CIPHER can run real tools on your device and analyze the results live.
// TOOLS AVAILABLE DEPEND ON YOUR TERMUX SETUP
nmap whois ping subfinder httpx nuclei waybackurls ffuf sqlmap dalfox
Install any tool in Termux and CIPHER will automatically detect and use it.
SETUP GUIDE
1
GET TERMUX
Download Termux from F-Droid (not Play Store). Then run:
pkg update && pkg upgrade -y
pkg install python nmap -y
pip install requests
2
GENERATE YOUR TOKEN
Scroll up and click GENERATE BRIDGE TOKEN. A unique install command will appear — copy it.
3
RUN IN TERMUX
Paste your install command in Termux and run it. The bridge will download and connect automatically.
4
USE THE AI TERMINAL
Go to AI Terminal and type bridge connect. CIPHER will confirm your bridge is live.
!
KEEP IT RUNNING
Keep Termux open in the background. Use a wake lock to prevent Android from killing it. Bridge goes OFFLINE when Termux closes.
