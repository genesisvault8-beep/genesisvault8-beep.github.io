WHAT IS IMAGE METADATA?
▼

Every photo taken with a camera or phone contains hidden data called EXIF data (Exchangeable Image File Format).

This data is invisible to the naked eye — it is embedded inside the image file itself. Most people have no idea their photos contain this information.

WHAT EXIF DATA CAN CONTAIN
  • 📍 GPS coordinates — exact latitude and longitude
  • 📷 Camera make and model (iPhone 14, Samsung S23, etc.)
  • 🕐 Exact date and time the photo was taken
  • 📁 File format, size, and resolution
  • 🔧 Camera settings (shutter speed, ISO, aperture)
  • 👤 Device owner name (sometimes)
  • 🔄 Image orientation and editing software used
💡 REAL WORLD
In 2012, John McAfee (antivirus founder) was a fugitive hiding in Guatemala. He was found because a journalist posted a photo with him — and the EXIF data contained GPS coordinates revealing his exact location.
2
HOW TO EXTRACT METADATA
▼

There are multiple ways to extract EXIF data from images depending on your tools and situation.

METHOD 1 — ONLINE TOOLS (Easiest)
  • jimpl.com — upload any photo, see full EXIF including GPS map
  • exifdata.com — detailed metadata viewer
  • metapicz.com — simple and fast
  • pic2map.com — shows GPS location on a real map
METHOD 2 — COMMAND LINE (ExifTool)

ExifTool is the most powerful metadata tool. Install it on any OS:

# Install on Linux / Termux
pkg install perl
cpan Image::ExifTool

# Read all metadata from a photo
exiftool photo.jpg

# Extract only GPS data
exiftool -GPS* photo.jpg

# Extract all metadata to a text file
exiftool photo.jpg > results.txt
METHOD 3 — PYTHON
from PIL import Image
from PIL.ExifTags import TAGS

img = Image.open("photo.jpg")
exif = img._getexif()

for tag_id, value in exif.items():
  tag = TAGS.get(tag_id, tag_id)
  print(f"{tag}: {value}")

READING GPS COORDINATES
▼

GPS coordinates in EXIF data are stored in a format called DMS (Degrees, Minutes, Seconds). You need to convert them to decimal to use in Google Maps.

EXAMPLE EXIF GPS OUTPUT
GPS Latitude : 48 deg 51' 30.00" N
GPS Longitude : 2 deg 17' 40.00" E
GPS Altitude : 35 m Above Sea Level
HOW TO CONVERT TO DECIMAL
Decimal = Degrees + (Minutes/60) + (Seconds/3600)

48 + (51/60) + (30/3600) = 48.8583° N
2 + (17/60) + (40/3600) = 2.2944° E

# Paste into Google Maps: 48.8583, 2.2944
# Result: Eiffel Tower, Paris, France 🗼
SHORTCUT — PASTE DIRECTLY INTO GOOGLE MAPS

Many tools give you decimal coordinates directly. Just paste them into Google Maps search bar and hit enter. It will drop a pin on the exact location.

🎯 OSINT TIP
Even if GPS is stripped, you can sometimes identify a location from landmarks, signs, shadows (for time of day), or vegetation visible in the photo. This is called geolocation by visual analysis.

FILE TYPE & FORMAT ANALYSIS
▼

Beyond GPS, the file type and format can reveal important intelligence about the target.

WHAT THE FILE TYPE TELLS YOU
  • .HEIC — Taken on iPhone (iOS 11+). Apple's format.
  • .JPG / .JPEG — Most common. Android, cameras, web.
  • .PNG — Screenshot or edited image. Often stripped of EXIF.
  • .DNG / .RAW — Professional camera. Contains rich metadata.
  • .WEBP — Web-converted image. Usually stripped of GPS.
WHAT THE CAMERA MODEL TELLS YOU
  • iPhone model → approximate year and income level
  • Samsung model → Android user, region (some models are region-specific)
  • DSLR camera → professional or serious photographer
  • Drone model → aerial photographer, potential tech knowledge
CHECK FILE MAGIC BYTES (ADVANCED)

Every file type has a unique signature in its first few bytes called magic bytes. This reveals the true file type even if the extension is changed.

# In Termux or Linux
file photo.jpg

# Check magic bytes manually
xxd photo.jpg | head -2

# JPG magic bytes: FF D8 FF
# PNG magic bytes: 89 50 4E 47
# PDF magic bytes: 25 50 44 46
