// STEP 1 — INSTALL TERMUX
⚠ WARNING: Do NOT install Termux from Google Play Store. It is outdated and broken. Use F-Droid only.
// STEP 01

Download F-Droid

F-Droid is a free app store for open-source Android apps. Termux on F-Droid is always up to date.

# Visit this URL on your Android browser:
https://f-droid.org

Tap Download F-Droid → install the APK → open F-Droid → search Termux → install.

// STEP 02

Allow Unknown Sources

Android blocks APK installs by default. You need to allow your browser to install apps.

Android 8+: Settings → Apps → Special App Access → Install Unknown Apps → enable for your browser.
// STEP 03

First Launch — Update Everything

Open Termux. You'll see a black terminal. Run these commands immediately after install:

pkg update && pkg upgrade

This will take a few minutes. Type Y and press Enter when asked. Wait for it to finish.

// STEP 04

Grant Storage Permission

To access your phone's files from Termux, run:

termux-setup-storage

A popup will appear — tap Allow. Now you can access your SD card and internal storage.

// STEP 2 — TERMINAL BASICS
// TIP: In a terminal, you type a command and press Enter to run it. There is no mouse — only keyboard.
// STEP 05

Where Am I? (pwd)

pwd means "Print Working Directory" — it shows you which folder you are currently in.

pwd
# Output example:
# /data/data/com.termux/files/home
// STEP 06

List Files (ls)

ls lists all files and folders in your current location.

ls
# Show hidden files too:
ls -la
// STEP 07

Move Between Folders (cd)

cd means "Change Directory" — it moves you into a folder.

# Go into a folder:
cd Downloads

# Go back one level:
cd ..

# Go to home directory:
cd ~
// STEP 08

Create & Delete Files/Folders

# Create a new folder:
mkdir myfolder

# Create a new empty file:
touch myfile.txt

# Delete a file:
rm myfile.txt

# Delete a folder and everything in it:
rm -rf myfolder
⚠ CAREFUL: rm -rf deletes permanently. There is no undo or trash bin.
// STEP 09

Read a File (cat)

Use cat to display the contents of a text file.

# Print file contents to screen:
cat myfile.txt

# Write text into a file:
echo "Hello Vault" > myfile.txt

# Read it back:
cat myfile.txt
// STEP 3 — INSTALLING PACKAGES
// pkg is Termux's package manager. It lets you install tools and programs with one command.
// STEP 10

Install Your First Tools

These are essential tools every Termux user should have:

# Install Python:
pkg install python

# Install git (for downloading code):
pkg install git

# Install curl (for web requests):
pkg install curl

# Install wget (file downloader):
pkg install wget

# Install nano (simple text editor):
pkg install nano
// STEP 11

Install Multiple Packages At Once

pkg install python git curl wget nano -y

The -y flag auto-confirms all prompts — no need to type Y every time.

// STEP 12

Edit a File With Nano

Nano is a beginner-friendly text editor inside the terminal.

# Open or create a file:
nano myfile.txt

# Type your text, then:
# CTRL + X → exit
# Y → confirm save
# Enter → keep filename
// STEP 13

Run a Python Script

# Create a simple python file:
echo 'print("Genesis Vault activated!")' > hello.py

# Run it:
python hello.py

# Output:
# Genesis Vault activated!
